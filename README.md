# Student Performance Analysis using SPSS

## Project Overview
This project analyzes student academic performance using IBM SPSS Statistics.

## Tools Used
- IBM SPSS Modeler
- Microsoft Excel
- Data Visualization

## Objectives
- Analyze factors affecting student performance
- Generate statistical reports
- Build predictive models

- report.pdf
